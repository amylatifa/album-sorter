For my personal project, I decided to create a website that sorts out a list of 10 albums inputted by the user. Aside from CS, I am also studying Music Technology. I wanted to combine my interests in programming and music through this site. The target audience here is music fans. They can use the sorter to determine a ranking of their favorite albums, or to compare their own preferences with a friend's ranking if they would like. My project was inspired by the Pop Sorter on tumblr. The difference between my project and that sorter is that mine includes album cover art, has a definitive ranking and doesn't allow two things to have the same ranking. Additionally, rather than ranking songs, you are ranking albums of your choice.

Project Instructions:

To get started, open up a live server. From there, enter an album title in the search bar. Then, click the "Add Album" button. A list of the most relevant results will be displayed. Click the correct album title. Repeat this process 9 more times. Once all 10 albums have been inputted, a JavaScript alert will pop up indicating that sorting will begin. From there, you will be presented with a prompt asking you to choose between two albums. Enter "1" or "2" to pick your preference. This process will repeat until every album in the list has been compared. Once the sorting is done, there will be an alert indicating its completion. A table will then be generated ranking albums from favorite to least favorite based on your choices listed with title, artists, and cover art.

Design Process:

In order to achieve this, I used HTML, CSS, and JavaScript functions to compare different pairings of albums. I started out by writing the HTML and CSS files so that I had a skeleton of my design. In the HTML, I first made sure to link the CSS and JavaScript files. I wanted the album rankings to be displayed as a table, so I created a table heading with the ranking, album cover art, album title, and artist name. I also used table body tags, but left them empty as I wanted the body to be generated only after the sorting was complete. Since I was planning on using the iTunes API to collect album data, I used the form tags to allow the user to type in the titles of the albums they want to sort. I also added an "Add Album" button next to the form, but hadn't implemented it yet. Once I had a basic design set up with the HTML and CSS, I started working on the JavaScript. Before I started writing any code, I did some research on comparisons in JavaScript and practiced advanced tutorials on W3Schools to brush up on my skills. 

When it came to the JavaScript, I knew I needed 4 main functions: one that fetched data from the iTunes API, one that added selected albums to an array, a prompted comparison using a bubble sorting algorithm, and one that added rankings to the empty table. Additionally, I made a function for the "Add Album" button in my HTML. The JavaScript took me a few days to implement for a couple of reasons. Although I have a particular proficiency in markup languages, JavaScript was a language I hadn't used in a number of years. So, I consulted W3Schools and Copilot to implement buttons, fetch the necessary API data I needed for album information, and to display the final ranking. I had particular trouble with my sort() and displayRankings() functions. While the functions themselves were working as they were supposed to, they weren't using my albumData array. Instead, what it displayed was "undefined by undefined." These issues persisted for approximately 2 hours, at which point I decided to go to Copilot and ask it to check what is causing the correct information to not be displayed. Apparently the issue had to do with the API, which wasn't being fetched properly. Since the data wasn't being fetched, the script just went to the sorting process with an empty array. To fix it, Copilot added a try and catch in the getAlbum function, and created a copy of the albumData array. Once that was fixed, the site started working as intended. 

Now that I had the essential aspect of my project working, I went back to the CSS and started styling the page. I wanted the design to be minimalistic, but modern and appealing. I styled the button to be round and change color on hover, and added a delay to it as well. When I was trying out the website, I realized there was no way to refresh the page after the final ranking was displayed, so I added a refresh button next to the add album button and created a corresponding function for it in my JavaScript. I made it so you can click the refresh button at any point for whichever reason, whether you changed your mind about which albums you want to rank or just want to do a new ranking after everything has been sorted. 

After I recorded a demonstration of my website, I realized there were some accessibility issues. The form box was actually quite small and a little hard to see, so I went back into the CSS file and expanded the form's size, added a visible border, and made the font size bigger. This also made my button placements look a lot less awkward, as instead of being next to the form they were under it and centered. I thought the black text color on a blue background looked a little off on the table, so I changed it to white to match the rest of the page better. Once I was satisfied with the design and had peers test it out, the project was officially complete.
